GitHub Pages と Eleventy でブログを作りました。この記事は**書き方のサンプル**です。
最初の段落は、記事一覧に「抜粋」として表示されます。

## 記事の追加のしかた

`_posts` フォルダに、次の名前で Markdown ファイルを作って push するだけです。

```text
_posts/YYYY-MM-DD-英数字のタイトル.md
```

ファイルの先頭には、`---` で囲んだ **Front Matter**（記事の設定）を書きます。
`tags` には「備忘録」「技術系」「日記」「読書メモ」のうち、**1つだけ**を書きます。

```yaml
---
title: 記事のタイトル
tags: [技術系]
---
```

## 画像

画像は `assets/images/` に置いて、次のように書きます。

```md
![画像の説明](/assets/images/sample.png)
```

> ⚠️ スマホで撮った写真には位置情報（EXIF）が含まれていることがあります。
> 公開する前に削除しておきましょう。

## リンクカード

他のサイトの記事は、URL を次のように書くと、タイトル・説明・画像のカードで表示されます。

{% raw %}

```liquid
{% linkcard "https://example.com/article" %}
```

{% endraw %}

### 書くときのルール

1. **1行で書く**（途中で改行しない）
2. **前後を空行にする**（文章とくっつけない）
3. URL は `"` で囲み、`https://` から書く

{% raw %}

```md
参考にした記事はこちらです。

{% linkcard "https://example.com/article" %}

この記事によると……
```

{% endraw %}

前後を空行にしないと、カードが文章の段落に入り込んで、レイアウトが崩れることがあります。

### うまく表示されないとき

- **URL だけのカード**になったときは、リンク先の情報を取得できていません。URL の打ち間違いか、相手のサイトが一時的に見られない可能性があります（記事の公開は止まりません）
- **ビルドがエラーで止まった**ときは、`https://` で始まる URL になっているかを確認してください

### 注意

- 紹介できるのはタイトル・説明・画像まで。**他の人の記事の本文を貼り付けるのは無断転載**になります
- 本文を使いたいときは、必要な部分だけを `>` で引用し、出典（タイトルと URL）を書きます
