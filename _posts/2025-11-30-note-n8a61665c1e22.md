## git push --force-with-lease <branch名>

私のチームの開発は、マージする前にコミットをまとめてからマージします。

```bash
% git rebase develop

% git rebase -i HEAD~<まとめたいコミット数>

% git push --force-with-lease <branch名>
```

最後の<strong>\--force-with-lease</strong>は、push -fよりちょっとだけ安全に力でpushできる方法です。  
ローカルとリモートを比較して、ローカルが最新か判断して、ローカルが最新でない場合はpushが失敗する  
私は長いので、aliasに保存しました。

## git switch

git checkoutを使っていたのですが、先輩に教えてもらってから使うようになったコマンド  
コマンド的にシンプルでわかりやすいのと、できることが限られるので、typoで予想外のことが起こりにくいメリットがあると思っています

<strong>switch</strong>：branchの切り替えや新しいbranchの作成に特化。コマンドがシンプルでわかりやすい  
<strong>checkout</strong>：branchの切り替えや新しいbranchの作成に加えて、作業ディレクトリのファイルの変更や復元にも使用

コマンドの違いはこんな感じ

```bash
% git switch -c <branch名>

% git checkout -b <branch名>
```
